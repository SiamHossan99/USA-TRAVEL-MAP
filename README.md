# USA Travel Map

An interactive map of the 50 US states, created by Siam Hossan with AI assistance from ChatGPT.

## Live website

https://siam-usa-travel.siamshouvo710.chatgpt.site

## Features

- Click or tap a state to mark it visited; click again to remove it.
- View your state count, percentage and progress bar.
- Choose states from an accessible list, or use the keyboard on the map.
- Save visits separately in each visitor's browser using localStorage.
- Responsive layout for phones and computers.

## Run locally

Download the files into one folder and open index.html in a browser. No installation or build step is required.

## Files

- index.html: page structure and SVG state boundaries
- style.css: layout, colors and responsive styles
- app.js: selections, progress calculations and browser storage

## Technologies

HTML, CSS, JavaScript and SVG. The original prototype used Python and Plotly; this interactive web version uses JavaScript.

## Credits

US boundaries adapted from US Atlas (https://github.com/topojson/us-atlas), which distributes public-domain US Census Bureau cartographic data. Built with assistance from ChatGPT. Browser storage stays on the visitor's device and does not sync between devices.
